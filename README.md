# University Event Management System (UEMS)

A web-based University Event Management System that lets users register, log in, view events, and manage event details.

## 📌 Project Summary

UEMS is a simple event management application built with PHP, JavaScript, CSS and designed for university use. It provides:

- User registration & login
- Event listing
- Profile management
- Simple UI for event handling


## 🧩 Technologies Used

- **Backend:** PHP  
- **Frontend:** HTML, CSS, JavaScript  
- **Data Storage:** MySQL
- **Assets & Includes:** CSS, images, reusable components

## 📁 Project Structure
```
/
├── api/ # Server endpoints (PHP)
├── assets/ # Stylesheets & images
├── includes/ # Reusable PHP parts (header/footer)
├── login/ # Login page logic
├── profile/ # User profile page
├── register/ # Registration logic
├── index.php # Main landing page
└── README.md
```

## 🚀 Installation

1. Clone the project:
   ```bash
   git clone https://github.com/sakai-aigga/University-Event-Management-System-UEMS-.git
2. Move into project folder:
   ```bash
   cd University-Event-Management-System-UEMS-
3. Setting up Database (MySQL):
  - Create a database
  - Import your SQL file
  - Update database config in your PHP files
4. Serve on a local server (e.g., XAMPP, WAMP):
  - Place the project inside htdocs (for XAMPP)
  - Start Apache and MySQL
  - Visit: http://localhost/University-Event-Management-System-UEMS-/
